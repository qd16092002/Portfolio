**Subtle + Smooth + Professional**

Ưu tiên:

- Small reveal.
- Fade.
- Translate.
- Scale rất nhẹ.
- Smooth hover.
- Micro interaction.

Tránh:

# 38. DEFINITION OF DONE

Chỉ xem nhiệm vụ hoàn thành khi:

- Website build thành công.
- Không còn lỗi nghiêm trọng.
- Các page chính hoạt động.
- Navigation hoạt động.
- Button quan trọng hoạt động.
- Không còn horizontal overflow bất thường.
- Mobile 375/390px sử dụng tốt.
- Tablet sử dụng tốt.
- Laptop sử dụng tốt.
- Desktop sử dụng tốt.
- UI nhất quán.
- Animation mượt.
- Code sạch hơn đáng kể.
- Không còn unused code rõ ràng.
- Nội dung giả không được thêm vào.
- Project giữ đúng công nghệ hợp lý.
- Không có dependency thừa do quá trình chỉnh sửa.

# 39. WHEN SOMETHING IS UNCLEAR

Nếu vấn đề liên quan design/implementation mà bạn có thể tự đưa ra quyết định hợp lý:

**Hãy tự quyết định và tiếp tục.**

Không dừng công việc để hỏi tôi những câu như:

> Bạn muốn padding 64px hay 72px?

Hãy hành xử như một Senior Designer/Engineer.

Chỉ cần hỏi nếu thiếu thông tin có thể khiến bạn:

- Bịa thông tin cá nhân.
- Thay đổi business/content quan trọng.
- Xóa functionality quan trọng.
- Cần credential.
- Cần dữ liệu mà source không có.
